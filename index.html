帶運機滾輪統計表 估算單

操作方式

  • 1. 點擊「新增項目」增加帶運機規格。
  • 2. 輸入名稱、選擇寬度與帶運機種類。
  • 3. 輸入直線距離 (mm)。
  • 4. 點擊「生成數據」產出各項清單。
  • 5. 點擊「匯出 EXCEL」完成估算作業。
  • 6. 數據生成為一次性，若要使用請記得匯出EXCEL

計算邏輯

  • 主帶運機模式：
    前行輪 = (L - 7000 [托架空間]) / 1000
    回程輪 = (L - 2000 [托架空間]) / 2000
    皮帶 = (L × 2 + 4000) / 1000 (M)
  • 入庫帶運機模式：
    前行輪 = (L - 4000 [托架空間]) / 1000
    回程輪 = (L - 2000 [托架空間]) / 2000
    皮帶 = (L × 2 + 4000) / 1000 (M)
  • 分料帶運機模式：
    皮帶 = (L × 2 + 400) / 1000 (M)
    其餘採用固定配件組合。
  • 回程輪規則：
    總數需扣除 1 組更換為螺旋式。
  • 備品規則：
    全案固定加增一次性備用滾輪，不隨機台數量累加。
